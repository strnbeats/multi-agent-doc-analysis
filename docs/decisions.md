# Архитектурные решения

- SQLite используется напрямую через стандартный `sqlite3`, без ORM.
- Схема SQLite управляется Alembic; SQLAlchemy используется только механизмом миграций.
- Анализы выполняются последовательно одним worker внутри процесса FastAPI.
- API фоновой задачи основан на статусах `queued/running/completed/failed`.
- Исходные документы являются временными и удаляются после обработки.
- Вероятность нейрослопа — эвристическая оценка исходного документа от 0 до 1.
- Лимиты MVP: загрузка 100 МБ, извлечённый текст 250 000 токенов.
- Gradio и внешняя очередь задач отложены до следующего этапа.
- `APP_MODE=mock` является штатным режимом локального запуска и сквозных API-тестов.
